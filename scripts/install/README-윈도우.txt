VEXPLOR AAS Studio — 윈도우 설치 안내
====================================

준비물
------
Docker Desktop for Windows
  https://www.docker.com/products/docker-desktop
  (설치 후 한 번 실행해서 고래 아이콘이 멈출 때까지 기다리십시오)

설치
----
1. 설치.bat 를 두 번 클릭
2. 메모장이 열리면 아래 한 줄만 채우고 저장 → 창을 닫습니다
       POSTGRES_PASSWORD=아무거나정하세요

   (AAS_TOKEN 은 비워 두십시오. 사내 누구나 열고 고칠 수 있게 됩니다.
    특정 사람만 쓰게 하려면 그때 값을 넣으면 됩니다.)
3. 설치.bat 를 다시 두 번 클릭

끝나면 브라우저에서 http://localhost:8080 으로 들어갑니다.
토큰을 비워 뒀다면 바로 열립니다.
나중에 AAS_TOKEN 을 채웠다면 「접근 토큰이 필요합니다」 화면에 그 값을 넣으십시오.

평소 사용
---------
  실행.bat   컴퓨터를 껐다 켠 뒤 다시 시작할 때
  중지.bat   잠시 내릴 때 (자료는 남습니다)

다른 컴퓨터에서 접속하기
------------------------
같은 사무실 네트워크라면 이 컴퓨터의 IP로 접속됩니다.
  명령 프롬프트에서  ipconfig  → IPv4 주소 확인
  다른 PC 브라우저에서  http://그주소:8080

막힐 때
-------
- 화면이 안 뜬다        → Docker Desktop이 켜져 있는지 확인
- 원인을 보고 싶다      → 명령 프롬프트에서  docker compose logs app
- 포트를 바꾸고 싶다    → .env 의 APP_PORT 를 고치고 실행.bat
