VEXPLOR AAS Studio — 맥 설치 안내
=================================

준비물
------
Docker Desktop for Mac
  https://www.docker.com/products/docker-desktop
  🔴 애플 실리콘(M1~M4)용을 받으십시오. 이 꾸러미는 애플 실리콘용입니다.
  🔴 설치할 때 Docker 아이콘을 반드시 "응용 프로그램" 폴더로 끌어다 놓으십시오.
     DMG 창에서 바로 실행하면 재부팅 후 사라집니다.

설치
----
1. 설치.command 를 두 번 클릭
   ("확인되지 않은 개발자" 경고가 나오면 우클릭 → 열기 → 열기)
2. 편집기가 열리면 아래 한 줄만 채우고 저장 → 닫습니다
       POSTGRES_PASSWORD=아무거나정하세요

   (AAS_TOKEN 은 비워 두십시오. 사내 누구나 열고 고칠 수 있게 됩니다.
    특정 사람만 쓰게 하려면 그때 값을 넣으면 됩니다.)
3. 설치.command 를 다시 두 번 클릭

끝나면 브라우저에서 http://localhost:8080 으로 들어갑니다.
토큰을 비워 뒀다면 바로 열립니다.
나중에 AAS_TOKEN 을 채웠다면 「접근 토큰이 필요합니다」 화면에 그 값을 넣으십시오.

평소 사용
---------
  실행.command   컴퓨터를 껐다 켠 뒤 다시 시작할 때
  중지.command   잠시 내릴 때 (자료는 남습니다)

  상태를 보고 싶으면 터미널에서  docker compose logs -f app

다른 컴퓨터에서 접속하기
------------------------
같은 사무실 네트워크라면 이 맥의 IP로 접속됩니다.
  터미널에서  ipconfig getifaddr en0  → 주소 확인
  다른 PC 브라우저에서  http://그주소:8080

🔴 맥이 잠자기에 들어가면 접속이 끊깁니다.
   상시 운영하려면 시스템 설정 → 배터리(또는 에너지 절약)에서 잠자기를 끄십시오.
