# 원격 수집기(VEXPLOR Edge) 연결 — 이 서버 쪽

*English: [edge-install.md](edge-install.md)* · 규격 사본: [엣지계약.md](엣지계약.md)

원격 수집기는 2.7.0 부터 **별도 오픈소스**입니다 — [waceinc/vexplor-edge](https://github.com/waceinc/vexplor-edge)
(Apache-2.0, 자기 판 1.0.0 부터). 공장 PC 에 까는 법 · 배치(DMZ · 설비망) · 연결하는 곳 전부 · 비밀번호와 인증서 · 지우기는
그 저장소의 [설치 안내](https://github.com/waceinc/vexplor-edge/blob/main/docs/%EC%84%A4%EC%B9%98.md)에 있습니다. 이 문서는
AAS Studio 서버에서 하는 일만 다룹니다.

## 언제 쓰나

| 서버 위치 | 설비 값을 읽는 것 |
|---|---|
| 설비와 같은 망(공장 안 서버) | 이 서버 안의 수집기 — 오른쪽 「수집」 칸. 원격 수집기가 필요 없습니다 |
| 공장 밖(클라우드 · 본사) | 공장 PC 한 대의 VEXPLOR Edge — 승인한 목록만 읽어 HTTPS 로 밖에만 보냅니다 |

## 원클릭 연결

1. **설정 → 원격 수집기 (VEXPLOR Edge)** 를 엽니다. 「원격 수집이 꺼져 있습니다」가 보이면 관리자가 **「원격 수집 켜기」**를
   누릅니다(`EDGE` 를 비워 둔 서버. `EDGE=on` 이면 늘 켜져 있고, `EDGE=off` 면 켤 수 없습니다).
2. **「+ 수집기 연결」** — 공장 PC 가 찾아올 이 서버의 주소(**https**)와 지금 읽을 목록(설비 · 태그 수)을 확인합니다.
   「이 목록을 바로 읽게 승인」을 켜 두면 승인도 함께 끝납니다. 읽을 태그가 없으면 설비 파일에 먼저 수집 연결(AID)을
   만듭니다 — 파일을 연 뒤 오른쪽 「수집」의 「수집 연결 만들기」.
3. **「연결 명령 만들기」** — 나온 한 줄을 공장 Linux PC(x64 · arm64)의 터미널에 붙여 넣습니다.

   ```bash
   curl -fsSL https://github.com/waceinc/vexplor-edge/releases/latest/download/get.sh | sudo sh -s -- --server https://aas.example.com --code 7KQ4-M2XD-9PRT
   ```

4. 화면이 그 PC 이름과 **「받는 중」**을 보여 주면 끝입니다. 값은 그 설비 파일의 「수집」 칸에 저절로 들어옵니다.

명령의 코드는 24시간 동안 한 번만 쓸 수 있습니다. 미리 승인하지 않았으면 「연결된 수집기」에서 **「목록 보고 승인」**을
누릅니다 — 승인 전에는 아무것도 읽지 않고, 승인을 기다리는 수집기는 10초마다 묻기 때문에 승인하면 곧바로 읽기 시작합니다.

## 연결한 뒤

| 화면에 보이는 것 | 뜻 |
|---|---|
| 받는 중 | 3분 안에 묶음이 왔습니다 |
| 첫 값 기다리는 중 | 승인됐지만 아직 묶음이 오지 않았습니다 |
| 승인 대기 | 사람이 읽을 목록을 승인해야 합니다 |
| 끊김 | 3분 넘게 소식이 없습니다 — 공장 PC 전원 · 서버로 나가는 길(443 · 프록시)을 확인합니다 |
| 일시 정지 중 · 해지됨 | 사람이 멈췄습니다. 일시 정지는 「다시 시작」, 해지는 새 명령으로 다시 연결 |

장치마다 마지막 수신 시각 · 받은 값 수 · 읽는 태그 수 · 설비 연결 수 · 보내지 못하고 쌓인 묶음 수 · 수집기 판이 나옵니다.
승인한 뒤 파일이 바뀌면 「승인한 뒤 파일이 바뀌었습니다」가 뜨고, 「다시 승인」을 누를 때까지 수집기는 승인한 목록 그대로 읽습니다.

## API 로 할 때

화면이 쓰는 경로는 [엣지계약.md](엣지계약.md) 8절에 있습니다 — `GET /edge/status` · `POST /edge/enable` ·
`POST /edge/registration-codes`(`approve` 로 미리 승인) · `GET /edge/devices` · `…/read-list-preview` · `…/approve` ·
`…/pause` · `…/resume` · `…/revoke`.

## 현장 서버에 함께 설치

공장 서버 한 대에 AAS Studio 와 수집기를 함께 두려면 현장 설치 묶음의 `sudo ./install.sh --with-edge` 를 사용합니다
([현장설치.md](현장설치.md)). 묶음에는 VEXPLOR Edge 릴리스 꾸러미가 그 릴리스의 `SHA256SUMS` 로 대조된 채 들어 있습니다.
