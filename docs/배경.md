# 왜 만들었나 — 표준과 공장 사이의 일

AAS(Asset Administration Shell, IEC 63278)는 표준으로는 갖춰졌습니다. 메타모델과 API 명세가 나와 있고,
편집기 · 서버 · SDK 같은 공개 도구도 여럿 있습니다. 그런데 AAS를 실제 공장에 붙이는 사람이 부딪히는 일은
명세서 바깥에 있습니다. VEXPLOR AAS Studio는 그 일을 소프트웨어가 맡게 하려고 만들었습니다.

아래 표의 근거는 2026-10-18에 원문을 열어 확인한 것입니다. 원문 목록은 맨 아래에 있습니다.

## 1. 현장에서 부딪히는 일과 이 도구가 맡는 일

| 현장에서 부딪히는 일 | 근거 | VEXPLOR AAS Studio에서 |
|---|---|---|
| **이미 가동 중인 설비와 PLC에 붙이기** | 10년 치 AAS 연구를 정리한 리뷰 논문은 기존 시스템과의 통합이 단기 도입을 막을 수 있는 핵심 과제라고 짚습니다[1]. 국내 논문은 구축이 끝난 시스템에 AAS를 나중에 적용하면 PLC · 게이트웨이 펌웨어 · DB 구조까지 고쳐야 한다고 적습니다[2] | AAS 안의 AID(Asset Interface Description) 서브모델이 정한 주소대로 OPC UA · Modbus TCP · MQTT 설비에서 값을 모읍니다. 공장 PC에 두는 원격 수집기는 밖으로만 보냅니다. PLC 프로그램은 고치지 않습니다 |
| **AAS를 손으로 만드는 부담** | 도구 없이 AAS를 만들면 모든 단계를 손으로 하고 프로그래밍이 많이 든다는 연구가 있습니다[3]. Fraunhofer IOSB-INA는 기존 공장 도입이 아직 제한적인 주된 이유로 수작업과 전문지식을 듭니다[4] | 「견본으로 시작하기」로 다 채운 설비 1종에서 출발하고, 값 표 · CSV 설비 대장으로 여러 값을 한 번에 채웁니다. 규칙 49종이 무엇이 틀렸는지 짚고, 그중 19종은 자동으로 고칩니다 |
| **서브모델 템플릿이 아직 만들어지는 중** | IDTA 공식 목록에서 번호 109개 가운데 공개판이 있는 것은 65개이고, 44개는 개발 · 검토 · 제안 단계입니다(2026-10-18 조회, 번호 단위 집계)[5] | 공개된 IDTA 템플릿을 설치하면 값 표의 줄마다 필수 · 수집 · 선택이 붙어, 무엇을 채워야 하는지 보입니다 |
| **도구가 일마다 나뉘어 있음** | 공개 도구는 편집기(AASX Package Explorer) · 서버(Eclipse BaSyx, FA³ST) · 라이브러리(Eclipse AAS4J)로 나뉘어 있고, 현장 값 수집은 설정 파일로 태그와 주소를 직접 맞춰야 합니다[6][7][8] | 열기 · 고치기 · 검사 · Part 2 REST로 내주기 · 현장 값 수집 · OPC UA로 내주기를 웹 화면 하나에서 합니다 |
| **표준을 통과해도 제출처에서 떨어짐** | 국내 제출처 검증기(KOSMO Validator)는 semanticId 허용 목록 · 필수 서브모델 · 패키지 구조 같은 사업 규칙을 따로 봅니다. 그 규칙은 표준 문서에 없습니다 | 그 규칙을 린터(L3)로 구현해 제출 전에 거릅니다. 표준과 제출처가 어긋나는 곳은 정책으로 드러내 사용자가 정합니다 |

## 2. AAS가 현장에 없다는 뜻은 아닙니다

AAS를 실제 라인에 적용한 사례는 있습니다. Bosch Rexroth 울름 모델 공장은 기계를 바꾸거나 더할 때마다
통합 작업이 몇 달씩 걸리던 문제를 풀려고 기계와 모듈마다 AAS를 붙였고, 같은 플랫폼을 다른 사내 공장으로 넓히고
있습니다[9]. 독일 와이어 하네스 업체 7곳은 3년 과제로 제품 선택부터
압착기 구동까지 AAS로 연결해 시연했습니다[10]. 국내에서도 경상남도가 자동차 부품 산업을 대상으로 AAS 기반
제조 운영체제를 실증했습니다[11].

다만 그 사례들도 어려움을 적습니다. Bosch Rexroth 사례를 소개한 기사는 표준에 맞는 AAS를 만드는 일 자체가
많은 사용자에게 첫 번째 장벽이라고 적습니다[9]. 리뷰 논문은 도입이 아직
독일 등 유럽 일부에 몰려 있다고 결론짓습니다[1].

VEXPLOR AAS Studio가 줄이려는 것은 이 연결 작업입니다. AAS 표준을 대신하지 않고, 표준이 정한 그대로
공장 설비에서 값이 흐르게 합니다.
