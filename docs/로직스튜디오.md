# VEXPLOR AAS Studio 를 VEXPLOR Logic Studio 와 함께 쓰기

VEXPLOR AAS Studio 는 설비 한 대의 AASX 를 만들고 검사합니다. [VEXPLOR Logic Studio](https://wace.me/platform-logic-studio) 는
웨이스의 공장 통합 플랫폼(MES · PLM · ERP · QMS 등을 하나의 표 체계 위에서)입니다. 둘은 파일 하나로 연결됩니다 — 여기서 검사를
통과한 AASX 가 Logic Studio 에서는 설비 대장이 됩니다. 공장에 설치할 것도, 변환할 것도 없습니다.

이 안내는 AAS Studio 가 무엇을 어떻게 넘기는지를 다룹니다. Logic Studio 화면 설명은 Logic Studio 안에 있습니다.

## 1. 세 단계

| # | 어디서 | 하는 일 | 결과 |
|---|---|---|---|
| 1 | AAS Studio | **위반 0건**이 될 때까지 고치고 **AASX 내려받기** | 내려받기 창에서 고른 메타모델 버전(V3.0 · V3.1 · V3.2)의 완성된 AASX(아래 참고) |
| 2 | Logic Studio Cloud | **설비 화면**에 파일을 끌어 놓기 | 미리 보기 — 기종 · 설비 · 공장 · 라인 · 건너뛴 것 |
| 3 | Logic Studio Cloud | 미리 보기를 확인하고 가져오기 | 설비가 기종에 연결된 채로 설비 대장에 들어감 |

- **기종(Type)과 설비(Instance)** — 기종 파일(설비 모델)은 기종이 되고, 설비 파일(실물 한 대)은 설비가 됩니다. 같은 기종
  여러 대는 그 기종에 연결된 채로 남습니다.
- **다시 놓아도 됩니다** — 같은 파일을 다시 놓으면 바뀌는 것이 없고, 고친 파일을 놓으면 바뀐 것만 「변경 제안」으로 나와
  사람이 반영하거나 거절합니다. 저절로 지우거나 덮어쓰는 일은 없습니다.
- **메타모델 버전** — AAS Studio 2.9.0 은 파일을 들어온 버전으로, 새로 만든 모델을 V3.1 로 내려받습니다(사용법 §4-10).
  Logic Studio 가 V3.1 · V3.2 파일을 읽는지 확인되기 전까지는, Logic Studio 에 넘길 파일은 내려받기 창에서 **V3.0** 을 고르십시오.
- **공정 파일도 됩니다** — 공정 묶음(사용법 §7)의 회사 → 라인 → 공정 → 설비가 공장 · 라인 · 설비가 됩니다.

## 2. Logic Studio 가 파일에서 읽는 것

| AASX 에서 | Logic Studio 에서 |
|---|---|
| DigitalNameplate — 제조사 · 제품명 · 형식 · 일련번호 | 설비의 제조사 · 모델 · 일련번호 |
| HierarchicalStructures — 회사 · 라인 · 공정 | 공장 · 생산 라인 |
| globalAssetId | 설비와 이 파일을 묶는 키 — 같은 설비는 항상 같은 행 |
| AID(수집 연결)가 있으면 | 원격 수집기 읽을 목록 초안의 재료 — 실시간 값 연결이 제공되면 쓰입니다(아래 3) |

## 3. 실시간 값 — 준비 중

원격 수집기(`vexplor-edge`, [설치](엣지설치.md))는 공장 안 PLC 를 읽어 값을 밖으로만 보냅니다. 2.5.0 부터는 읽을 목록의
태그마다 힌트가 붙습니다 — 모델 요소의 `semanticId`, 제안 역할, 같은 파일의 한계값([계약 §4.1](엣지계약.md)). 받는 쪽은 이 힌트로
역할과 SPC 규격 한계를 미리 채워 두고 사람이 확인하게 할 수 있습니다. 하한(`lsl`)은 값과 semanticId 가 같은 `Range` 요소의
`min` 에서만 나옵니다. 짝지은 한계 속성은 상한만 줍니다([연동](연동.md)).

그 값을 Logic Studio Cloud 로 보내는 연결은 **준비 중이며 지금은 제공하지 않습니다.** 그때까지 값은 AAS Studio 가 직접
모으고 보관합니다(사용법 §8).

## 4. 무엇이 어디에 남나

- AAS Studio 는 Logic Studio 에 데이터를 쓰지 않습니다. Logic Studio 는 넘겨준 파일을 읽습니다.
- AASX 는 그대로 귀사의 것입니다. 제출용 원본 참조모델은 바꾸지 말고, 등록할 파일을 넘기십시오.
- Logic Studio 는 별도 약관이 있는 웨이스의 다른 제품입니다. AAS Studio 는 Apache-2.0 그대로이며 Logic Studio 없이도 동작합니다.
